# hacktiv8-triagemate-bug-triage-agent
TriageMate: a rule-based AI agent that turns raw bug reports into structured triage cards (severity, category, duplicates, missing info, next actions). Vanilla HTML5 + CSS3 + JavaScript, bilingual EN/ID. Built with vibe coding using IBM Bob.
Try it: open index.html in your browser, paste a bug report or click a sample, then press "Triage". Re-submit a similar report to see duplicate detection, and switch EN/ID in the header. No install or build needed.
